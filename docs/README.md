# コマあわせ 設計メモ

大学生が時間割を友だちと共有したり、重ねて空きコマを探したりするための Web アプリ「コマあわせ」の設計メモ。
2026-09-27 時点で決まっていることをまとめている。

## ひとことで

- 自分の時間割を登録して、画像で共有できる
- 友だちやグループの時間割と重ねて、みんなの空きコマがすぐわかる
- 同じ大学の授業データ（シラバス＋みんなの登録）から選んで登録するので、重ねたときに同じ授業がまとまる

## 大事な決定

| 項目 | 決定 |
|---|---|
| 名前 | コマあわせ（KomaAwase） |
| ログイン | メールアドレス or Google。パスキーが主役 |
| 大学アカウント | 必須にしない。大学メールでの在籍確認はバッジとして任意 |
| 公開範囲 | 初期は非公開。承認した友だちと、参加するときに見せると選んだグループだけが見られる |
| 学期 | 2学期制に固定しない。4学期制（クォーター）などを大学ごとに設定できる |
| 授業データ | 大学ごとに共有。各授業は「みんなと同期」か「自分だけ」を選べる |
| スクショ読み取り | Groq をメイン、Workers AI を予備にする。学習にデータを使われないサービスだけを使う |
| ホスティング | Cloudflare Workers（静的アセット配信）＋ D1 / Queues。資料のファイルとメールの送信はシンレンタルサーバー。公開先は `koma.tomakura.com`（`tomakura.com` の DNS は Cloudflare） |
| 最初の対象校 | デジタルハリウッド大学 |
