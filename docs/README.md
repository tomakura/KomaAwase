# コマあわせ 設計メモ

大学生が時間割を友だちと共有したり、重ねて空きコマを探したりするための Web アプリ「コマあわせ」の設計メモ。
2026-09-30 時点で決まっていることをまとめている。

## ひとことで

- 自分の時間割を登録して、画像で共有できる
- 課題とイベントを「予定」のタブでまとめて見られる。欠席と単位も数えられる
- 友だちやグループの時間割と重ねて、みんなの空きコマがすぐわかる
- 同じ大学の授業データ（シラバス＋みんなの登録）から選んで登録するので、重ねたときに同じ授業がまとまる

## 大事な決定

| 項目 | 決定 |
|---|---|
| 名前 | コマあわせ（KomaAwase） |
| ログイン | メールアドレス or Google。パスキーが主役 |
| 大学アカウント | 必須にしない。大学メールでの在籍確認はバッジとして任意 |
| 公開範囲 | 初期は非公開。承認した友だちと、参加するときに見せると選んだグループだけが見られる |
| 学期 | 2学期制に固定しない。4学期制（クォーター）などを大学ごとに設定できる |
| 授業データ | 大学ごとに共有。各授業は「みんなと同期」か「自分だけ」を選べる |
| スクショ読み取り | Groq（qwen3.8）をメイン、Workers AI（Llama 4 Scout）を予備にする。学習にデータを使われないサービスだけを使う |
| ホスティング | Cloudflare Workers（静的アセット配信）＋ D1 / Queues / Cron / Workers AI。資料のファイルとメールの送信はシンレンタルサーバー。公開先は `koma.tomakura.com`（`tomakura.com` の DNS は Cloudflare） |
| 通知 | Web Push。友だち・グループ・スクショの読み取り、授業の前、前の日の20時の課題と予定 |
| オフライン | PWA。一度開いた時間割は電波がなくても見られる。オフライン・不安定なときは帯で知らせ、いつの情報かと更新ボタンを出す |
| 最初の対象校 | デジタルハリウッド大学 |
