# 授業データの共有と大学ごとの情報

## なぜ共有するか

みんなが別々に授業名を手で打つと、「線形代数2」と「線形代数Ⅱ」のように表記がばらつく。そうなると、重ねたときに同じ授業だと判断できない。
そこで大学×年度ごとに共有の授業データを持ち、授業を追加するときはそこから選んでもらう。

## 同期するか、自分だけか

授業ごとに選べる（すごい時間割のやり方を参考にした）。

| | みんなと同期する | 自分だけで使う |
|---|---|---|
| 授業名・先生・曜日時限・教室 | 共有データから読む。だれかが直すと自動で反映 | 自分のコピーを持つ |
| 色・メモ・資料・課題 | 自分のもの | 自分のもの |
| 重ね表示 | 授業コード（`shared_course_id`）で確実にまとまる | 同じ大学で、授業名と曜日・時限が同じならまとめる |

## データの出どころ

1. シラバス：大学の公開シラバスから取り込む。授業コードがあれば同じ授業の判定に使う
2. みんなの登録：シラバスにない授業や、シラバスにない項目（教室など）を、同じ大学の人が登録する

## 最初の対象校：デジタルハリウッド大学

### 公開シラバス

- ログインなしで見られる公開シラバスがある
- 載っている項目

| 項目 | 使い道 |
|---|---|
| 授業コード | 同じ授業かどうかの判定 |
| 講義名 | 授業名 |
| 開講時期（年度とクォーター） | 学期 |
| 教員名 | 先生 |
| 曜日時限（集中授業もある） | コマの位置。集中授業は曜日・時限なし |
| 教室 | 載っていない。みんなの登録で埋める |

### 時限

- クォーター制
- 演習科目は2コマ続きが多い
- 時限の時刻は大学のひな形としてアプリ側に持つ

### 取り込み（2026-10-20〜）

- 大学から公開シラバスのデータを使う許可をもらった。教室名はシラバスにないので、みんなで入力する（教室予約の画面から運営が入れることも大学の許可済み）
- 取り込むのは授業コード・講義名・開講時期・教員名・曜日時限（隔週も）・単位数と、授業概要・到達目標・回ごとの授業内容。講義名の【】や「※旧…」の注記は外す。題に「オンデマンド」などがある授業は、教室を最初から「オンライン」にする
- 読み方：`scripts/syllabus/fetch.mjs` を手元の PC で動かす（シラバスの URL は渡すだけでリポジトリに書かない）。ブラウザが開くので、検索条件（開講年度学期・授業管理部署 大学）を選んで検索し、表示件数を100にしてから Enter。一覧の各授業を1秒に1件のペースで開いて読み、JSON に書き出す。学期ごとに同じファイルへ足していける。書き出したファイルは `.gitignore` 済み
- 入れ方：運営 →「シラバスの取り込み」でファイルを選び、「確かめる」で新しく入る・変わる・シラバスにない授業を見てから「取り込む」。授業コードで同じ授業を見分けるので、同じファイルを何度取り込んでも増えない。教室は消えない。変更はだれのものでもない変更として履歴に残り、同期している人には「変更あり」になる
- みんなの登録をシラバスの授業にするときは、ファイルの授業に `link`（共有授業の id）を書いて取り込む。どれをつなぐかはスレッドで確かめてから
- シラバスにない授業（前に取り込んだがファイルにないもの）は消さずに一覧に出すだけ
- シラバスの授業を時間割に入れると、メモが2つ（授業概要・到達目標、回ごとの授業内容）入る。いらなければ本人が消す。長いメモは最初の数行だけ見せて「続きを読む」で開く
- 同期中のシラバスの授業は、授業名・先生・曜日時限・単位数・授業の形がシラバスのまま（編集画面に「シラバス」の札）。教室だけは在籍確認済みの人ならだれでも入力でき、みんなに反映される。違うときは「自分だけで使う」で直す。運営は全部直せる
- 自分だけで使っている授業に、同じ名前で曜日・時限の重なるシラバスの授業が1つだけあると、編集画面に「シラバスとつなぐ」が出る。勝手にはつながない（在籍確認していない人がおかしくならないように）
- 教室に「遠隔」「Zoom」「リモート」などと書くと「オンライン」にそろえる（`src/lib/text.ts`）。前からあった分は 0032 でそろえた
