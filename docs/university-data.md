# 授業データの共有と大学ごとの情報

## なぜ共有するか

みんなが別々に授業名を手で打つと、「線形代数2」と「線形代数Ⅱ」のように表記がばらつく。そうなると、重ねたときに同じ授業だと判断できない。
そこで大学×年度ごとに共有の授業データを持ち、授業を追加するときはそこから選んでもらう。

## 同期するか、自分だけか

授業ごとに選べる（すごい時間割のやり方を参考にした）。

| | みんなと同期する | 自分だけで使う |
|---|---|---|
| 授業名・先生・曜日時限・教室 | 共有データから読む。だれかが直すと自動で反映 | 自分のコピーを持つ |
| 色・メモ・資料・課題 | 自分のもの | 自分のもの |
| 重ね表示 | 授業コード（`shared_course_id`）で確実にまとまる | 同じ大学で、授業名と曜日・時限が同じならまとめる |

## データの出どころ

1. **シラバス**：大学の公開シラバスから取り込む。授業コードがあれば同じ授業の判定に使う
2. **みんなの登録**：シラバスにない授業や、シラバスにない項目（教室など）を、同じ大学の人が登録する

## 最初の対象校：デジタルハリウッド大学

### 公開シラバス

- ログインなしで見られる公開シラバスがある
- 載っている項目

| 項目 | 使い道 |
|---|---|
| 授業コード | 同じ授業かどうかの判定 |
| 講義名 | 授業名 |
| 開講時期（年度とクォーター） | 学期 |
| 教員名 | 先生 |
| 曜日時限（集中授業もある） | コマの位置。集中授業は曜日・時限なし |
| 教室 | **載っていない**。みんなの登録で埋める |

### 時限

- クォーター制
- 演習科目は2コマ続きが多い
- 時限の時刻は大学のひな形としてアプリ側に持つ

### 取り込むときの注意

- robots.txt はなく、ページに利用規約も書かれていない。ただ、禁止されていないことと許可されていることは別。**サービスとして出す前に教務課に確認する**。CSV などで正式にもらえるなら一番確実
- 取り込むのは授業コード・講義名・開講時期・教員名・曜日時限だけ。授業概要や到達目標などの文章は先生の著作物なので、コピーせず公式ページへのリンクにする
- 1秒に1ページくらいのペースで、学期のはじめに1回だけ取り込む（Cron Triggers）
- 取り込みスクリプトはあとで作る
