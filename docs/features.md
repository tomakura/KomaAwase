# 機能と画面の流れ

## 画面一覧

| 画面 | できること |
|---|---|
| ログイン | パスキーでログイン（メール欄の候補からも選べる）。はじめての人は Google かメールアドレスで登録。「コマあわせとは」から紹介ページへ。退会と運営の画面を開く前は、ここでもう一度ログインする |
| コマあわせとは（`/intro`） | できることと、見せる相手を自分で決められること、はじめ方の紹介。ログインしていなくても読める。「はじめる」でログインへ。「その他」→「このアプリについて」からも開ける |
| はじめの設定 | 登録直後に、大学・学期の区切り・時限と時刻・表示する曜日を決める。そのあと、在籍確認できる大学なら在籍確認をすすめる画面が出る |
| 自分の時間割 | 学期（Q1〜Q4 など）の切り替え、今日と今の授業の表示、コマから詳細や追加へ |
| 授業をさがす | 空いたコマをタップすると開く。その曜日・時限の授業を共有データから選ぶ |
| 授業を追加・編集 | 授業名、先生（複数）、色（10色）、開講学期（複数）、曜日・時限と教室と隔週（複数）、単位数、欠席できる回数、同期するかどうか |
| 授業の詳細 | 授業が入ったコマをタップすると、時間割の上に下から開く。メモ・資料・課題・休講・イベントの追加・編集と一覧、欠席の記録、みんなの休講 |
| 予定（`/plans`） | 課題（授業のもの）とイベントを、今日・明日・今週のように分けて1つの一覧で見る。ここからも足せる |
| みんなの授業データ | 共有授業の内容・同期している人数・変更の履歴。前の内容に戻す、報告する |
| スクショから読み込む | ほかのアプリの時間割のスクショを AI で読み取り、見直してから保存する。注意書きに、画像の送り先も書く |
| コマを重ねる | 「友だち」の画面の上から開く。友だちやグループの時間割と重ねて、みんなの空きコマを探し、コピー・共有で送る |
| 画像で書き出す | 時間割を画像にして保存・共有する |
| 友だち | 届いた申請、友だち、グループ、送った申請。友だちの追加（リンク・コード・QR） |
| 友だちの時間割 | 友だちや、時間割を見せているグループのメンバーの時間割 |
| グループ | メンバー、時間割を見せるかの切り替え、招待リンク。作った人は、参加の承認、退出させた人の管理も |
| その他 | 時間割の管理、表示、通知、休講の共有、アカウント、データの書き出し、サポート |
| ログイン中の端末（`/more/sessions`） | ログインしている端末の一覧。なくした端末などをログアウトさせる |
| お問い合わせ（`/contact`） | 名前・メールアドレス・内容を運営に送る。ログインしていなくても送れる |
| 運営 | トップ（`/admin`）から、問い合わせ・通報・不具合・要望、利用者（警告・利用停止）、授業、利用者が作った大学、利用の状況へ（運営する人だけ）。「その他」の行に未対応の件数を出す |

## リンクを共有したとき

LINE・X などにリンクを貼ると出るタイトル・説明・画像は、`src/app.html` の `og:` タグで決める（どのページも同じ）。画像は `static/og.png`（1200×630）で、`node scripts/make-og.mjs static/og.png` で作り直す。

## はじめの設定

- メールか Google で登録し、ニックネームとパスキーを決めたあとに開く。終わるまで時間割は開かない
- 大学はひな形のある大学なら候補から選ぶだけで、学期（日付つき）と時限の時刻が入る。ひな形のない大学名もそのまま登録でき、同じ名前の人どうしで授業データを共有できる（`NFKC` で全角・空白をそろえる）。入力候補に出るのは、ひな形のある大学と、3人以上が使っている大学だけ。打ち込まれた名前は、3人になるまで、ほかの人の候補には出さない（冗談の名前や打ち間違いが広がらないように）
- 学期の区切りは2・3・4学期制から選び、名前・まとまり（前期など）・日付を1つずつ直せる。ひな形のない大学の日付は目安なので、その旨を出す
- 時限は1行ずつ時刻を直せるほか、「1限の始まり・時限の数・1コマの長さ・休み時間・昼休み」からまとめて作り直せる。0限も足せる
- 表示する曜日は7つのボタンでどれでも選べる（モックは土日だけの切り替えだったが、水曜が休みの人などのために広げた）
- テーマはここでは決めない（端末に合わせる。「その他」で変えられる）
- ニックネームを決める画面で、アイコン（写真・文字・色）もいっしょに決める。文字ははじめはニックネームの1文字目で、ニックネームを打つとついてくる
- 大学が在籍確認に対応していれば、終わったあとに在籍確認の画面（`/setup/verify`）が出る。できることを見せて、その場でメールを送れる。「あとで」で飛ばせる
- すでに時間割がある人（この画面ができる前に始めた人）は通らない

## 自分の時間割

- 授業が1つもないあいだは、時間割の上に始め方の案内を出す。在籍確認をしている人（と運営）には「スクショから読み込む」「授業をさがす」。していない人には、大学が在籍確認に対応していれば、「在籍確認をすると使えます」のカード（使えるようになる2つと「在籍確認する」）と「自分で入力する」を出す。対応していない大学の人と、大学が未設定の人には、「自分で入力する」だけを出す。「授業をさがす」の中の「スクショからまとめて読み込む」も、在籍確認をしている人にだけ出す

- 学期はタブで切り替える。4学期制なら Q1〜Q4。タブの上に前期・後期などのまとまりを出す
- 開いたときは今日の学期のタブ。学期と学期の間（夏休みなど）は次に始まる学期
- 時限の欄に開始と終了の時刻を出す
- 今日の曜日は丸で囲み、その列を少し濃くする
- 今受けている授業は、そのコマ自体を縦のプログレスバーにする（上から埋まっていく）。残り時間も出す
- 教室はコマの下に白い札で中央ぞろえ。休講は黒い札。自分では入れていないが、同じ授業を同期しているほかの人が2人以上休講にしている日は「休講かも」の札（[みんなの休講](#みんなの休講)）
- 授業名は単語の区切りで改行する。`Intl.Segmenter` で単語に分け、「学」「Ⅱ」のような1文字は前の語に、開きかっこは次の語につける（統計学｜入門、線形｜代数Ⅱ）。BudouX は「統計学入門」のような複合語を1つの文節として返すので、授業名には向かなかった。知らないカタカナ語は細かく切られる（エンジニア｜リ｜テラ｜シー）ので、3文字未満のカタカナの切れ端が続くときはつなぎ直す。コマの中では書き出しと同じ `wrap` でコマの幅に合わせて行を決め、ーや小さい仮名で行を始めない
- 1行に入りきらない長い語（コミュニケーションなど）は途中で折り返す。教室の札は必ず見えるようにし、はみ出すときは授業名のほうを切る
- 今日と今の時刻は日本時間で決める（授業の時刻は大学のある場所の時刻なので）
- 2コマ続きの授業は1つのコマとしてつなげて表示する
- 同じコマに授業が2つあるとき（隔週で入れ替わる授業など）は、コマの中に上下に並べる
- 隔週の授業は教室の札の頭に「奇」「偶」を付ける。今週ない隔週のコマは薄くし、授業中にもしない
- 曜日・時限のない授業（オンデマンド、集中講義）は、時間割の下に色付きのカードで並べる
- スクショの読み取りが終わると、上にお知らせを出す
- 右上から画像の書き出しへ

## 授業の追加

1. 空いたコマをタップする
2. 「授業をさがす」でその曜日・時限の授業が一覧で出る
   - 「シラバス」「みんなの登録（人数）」の札が付く
   - 同じ授業を取っている友だち（と、時間割を見せているグループのメンバー）のアイコンと名前も出る
   - 授業名・先生・授業コードで検索できる
   - まだだれも登録していないコマは、自分で入力するよう案内する
3. 選ぶと編集画面が開く。内容は共有データから入っている
4. 一番上で「みんなと同期する」か「自分だけで使う」を選ぶ。同期中に直した内容は同期しているみんなに反映される、と画面に書く
5. 見つからないときは「自分で入力する」か「スクショからまとめて読み込む」。自分で入力した授業も初期値は「みんなと同期する」で、次の人がさがせるようになる

週に何回かある授業は、1つの授業に曜日・時限を何個でも並べて一度に登録する。教室と、毎週・奇数週・偶数週は曜日・時限ごとに選ぶ。隔週は学期の始まる週を1週目として数える。

編集画面で直したまま別の画面へ戻ろうとすると、「変更を保存していません。戻りますか？」と聞く（「戻る」「編集を続ける」）。保存するときは聞かない。タブを閉じるときは、ブラウザの確認になる。

## 授業の詳細

- 時間割から開くと、時間割はそのまま後ろに残り、その上に授業が下から上がる。閉じるのは、ブラウザの戻る・後ろの暗い部分・下へのスワイプ・スマホの戻る操作で、開く前の時間割（同じ学期）に戻る。メモなどを変えても閉じない。開いたままのアドレスは授業のものなので、再読み込みすると授業の画面だけが開く（そこから閉じると時間割へ行く）
- 曜日・時限と教室、開講学期、先生、同期しているかを表示
- 共有データにつながっている授業は「みんなの授業データ（変更の履歴・報告）」へ
- 「追加する」の下に、メモ・資料・課題・休講・イベントの5つのボタン
- 課題はチェックボックスと締切までの日数（あと○日・今日まで・○日過ぎ）
- 休講の日の初期値は、次にその授業がある日
- 時間割のコマには、今日から1週間のうちにある休講を「休講 10/2」の黒い札で出す。休講の日はそのコマを授業中にしない
- 資料は PDF・写真・Word・PowerPoint・Excel。いくつかまとめて選べる。写真は送る前に縮める。1ファイル 10MB、全部の授業で 100MB まで。一覧の下に使っている容量を出す
- メモ・資料・課題は授業ごとに持つので、どの曜日・時限から開いても同じものが見える
- メモ・課題（名前と締切）・休講（日と一言）は、それぞれの行の「編集」から直せる。直しても、種類・足した日・並び順は変わらない
- メモは、日付の新しい順（同じ日は、あとから足したほうが上）で並ぶ。複数あるときは、見出しの「並び替え」で、行の上下の矢印で手で並べ替えられ、「完了」で保存する（並び替えているあいだは、編集と削除は出ない。並びが変わらなければ何も送らない）。並べたあとに足したメモは、いちばん上に入る
- イベントは、その授業の試験などを入れる。中身は[予定](#予定)のイベントと同じで、予定のタブにも出る。「授業の時間にする」をオンにすると、選んだ日のその授業の時刻（最初の時限の始まりから最後の時限の終わりまで）が入る。その日に授業がなければそう出す
- 「編集」から授業の編集画面へ

## 予定

- 下のタブの2つ目（前は「重ねる」だった。コマを重ねるは「友だち」の画面へ移した）
- 課題（授業の詳細で入れたもの）とイベントを1つの一覧にする。見出しは「期限が過ぎた課題」「今日」「明日」「今週」（日曜まで）「来週から」「期限なしの課題」「過ぎたもの・済んだもの」
- 同じ日の中では、時刻のあるイベント → 終日のイベント → 課題の順。過ぎたもの・済んだものは新しい順で、たたんである
- 右上の「追加」から課題かイベントを足す。課題は授業を選んで名前と締め切りを入れる（授業の詳細で足すのと同じ）
- イベントは授業につながらない予定（テスト・サークル・面接など）で、名前・日付・時刻か終日・場所・メモ。授業を選べば、その授業の詳細にも出る。授業を消してもイベントは残る
- 課題はチェックで済んだことにできる。イベントは行から直す・消す
- 前の日の20時に、明日締め切りの課題と明日のイベントを通知で知らせる（[通知](#通知)）
- 予定は本人だけのもの。友だちやグループには見せない

## 出欠と単位

- 授業の編集画面に「単位数」（0.5きざみ、20まで）と「欠席できる回数」（99まで）がある。どちらも任意
- 単位数は、同期している授業では共有データに入る（同じ授業の人みんなで同じ値）。欠席できる回数は本人のもの
- 大学に決まりがあるときは、空欄のままでも決まりの値を使う（欄に薄く出す）。今はデジタルハリウッド大学だけで、1コマ1単位、欠席は1単位につき2回まで
- 授業の詳細の「欠席」に、欠席した回数と上限を出す。「欠席した」で今日を記録する（1日1回）。あと1回で上限、上限に達した、超えた、を出す。記録した日は一覧にあり、まちがえたら消せる
- 「その他」→「時間割の管理」に、学期ごとの単位数と年度の合計を出す。いくつかの学期にまたがる授業は「複数の学期」にまとめ、合計では1回だけ数える。単位数のない授業は入れない
- 欠席は本人だけのもの。共有しない

## みんなの休講

- 同じ共有授業を「みんなと同期」で入れている人が休講を入れると、ほかの人にも人数だけが見える。だれが入れたかは出さない
- 数えるのは、在籍確認が切れていない人で、休講の共有をオンにしている人（「その他」の「休講を同じ授業の人に知らせる」。初期はオン）だけ。利用停止の人と自分は数えない
- 授業の詳細の「みんなの休講」に、今日から先の日と「○人が休講と入れています」を出す（1人から）。「休講にする」で自分の休講として入れられる。自分で入れた日は出さない
- 時間割のコマには、2人以上のときだけ「休講かも」の札を出す（今日から1週間のうち）
- まちがい・いたずらと思ったら「まちがい」で運営に伝える（1人1日につき1回）。運営が「その日の共有を消す」と、その授業のその日はだれにも出なくなる

## みんなの授業データ

- 共有授業の今の内容、年度と学期、同期している人数
- 変更の履歴を新しい順に、項目ごとの変更（授業名・先生・曜日・時限）で出す。だれが直したかは出さない
- 直せる（戻せる）のは、その授業を時間割に「みんなと同期」で入れていて、在籍確認が切れていない人と運営だけ。ほかの人が同期中の授業を直すと「自分だけで使う」になる（編集画面で先に伝える）
- 変更は50件ずつページ送りで見られる
- 前の内容に「この内容に戻す」で戻せる。戻すことも1つの変更として履歴に残るので、戻しすぎても戻せる。開いたあとにほかの人が直していたら止める
- 「まちがい・荒らしを報告する」から理由を選んで通報できる
- 見られるのは、その大学・年度の時間割を持っていて、在籍確認済みの人と運営だけ。在籍確認していない人には、授業の詳細に「在籍確認をすると、みんなの授業データを見られます」と出す
- 運営は、ここから授業名・先生・教室を直せる（履歴に残り、同期しているみんなに反映される）

## コマを重ねる

- 自分と、選んだ友だち・グループの時間割を1枚に重ねる。人は上のチップで選ぶ。グループのチップは、そのグループで時間割を見せているメンバーをまとめて選ぶ
- 下のタブではなく、「友だち」の画面の上の「コマを重ねる」から開く。戻ると友だちへ
- 選んだ人は次に開いたときも覚えている（Cookie）。URL（`?with=`）でも渡せる
- 1人ずつ、その人のアイコンで表す。授業もアイコンの色で塗り分ける（マスの左のすじと薄い地色）。同じ授業を複数人が取っていれば、その人たちの色を並べる。チップの枠と地色も同じ色
- 同じ授業を取っている人は、授業名を1つにまとめてアイコンだけ並べる。共有授業につながっていれば同じ授業、つながっていなければ同じ大学で授業名が同じものをまとめる
- 空きコマは強調しすぎず、枠線だけの空っぽのマスにする
- 1マスに入りきらないときは、全部の時限の高さを揃えて伸ばす。人を選び直して高さや曜日の数が変わるときは、格子がすーっと伸び縮みする。授業の札はふわっと出入りする（動きを減らす設定のときは、動かさない）
- 下に「みんな空いてるコマ」を曜日ごとに出す（モックは1コマ1つの札だったが、曜日ごとのほうが速く読める）。札は1つずつ少しずらして出入りする（動きを減らす設定のときは、ずらさない）
- 「コピー」「共有」で、空きコマを文にして送れる（「みんな空いてるコマ（年度 学期）」の下に「月 2限・4限」のように曜日ごと）。共有はスマホの共有シート、ないときはコピーになる
- 自分のほかにだれも選んでいないときは、全部のコマが「空き」になって意味がないので、札の代わりに「重ねる人を選ぶと出ます」（友だちがまだいないときは「友だちを追加すると出ます」）と出す
- コマをタップすると、だれがどの授業を受けているか（別の大学の人はその時刻）、教室、空いている人が出る
- 別の大学の友だちは時限の時刻が違うので、時刻で比べる（時限番号は使わない）。1分でも重なる時限は空きにしない。そのことを下に書く
- 自分は選んでいる学期、ほかの人は見ている日付（その学期の今日、学期外ならその学期の初日）の学期で重ねる。学期に日付がない人は同じ名前の学期
- 友だちの時間割の画面とグループの画面からも「重ねる」で開ける

## 画像で書き出す

- 縦長（1080×1920、ストーリー用）と横長（1920×1080、LINE・X 用）
- 表示を切り替えられるもの：教室名、曜日、時限、時刻、アイコンとニックネーム。教室名は初期状態で入れない。時限・時刻の列は、いちばん長い文字の幅に合わせる。選んだ設定はその端末に覚えておく
- 曜日と時限の欄は文字の分だけの幅にして、コマをできるだけ大きくする（モックでは欄が広すぎてコマが小さかった）
- すみに「コマあわせ で作成」の札を入れる。横長では上の行に置いてコマを大きくする
- 授業名は時間割と同じ単語の区切りで改行し、「ー」や小さい「ッ」を行の頭にしない
- 画像はブラウザの Canvas で描く。プレビューも同じ Canvas なので、見たままの画像が保存される。SVG を画像にする方法だと Web フォントが使えないためやめた
- 「画像を保存」と、ファイルを共有できる端末では「共有する」（共有シート）
- メモ・資料・課題・休講は画像に入れない。画像はいつもライトの配色

## スクショから読み込む

- 「授業をさがす」の「スクショからまとめて読み込む」と、授業がまだないときのホームから開く。「その他」には置かない
- 別の同意の画面は出さない。「読み込む前に」の2番目に、画像がGroq・Cloudflareへ送られること、読み取りが終わるとすぐに消すことを書き、「上のことを確認しました」にチェックを入れないと読み込めない。プライバシーポリシーへのリンクは、下の「1日◯回まで」の注に置く。チェックなしのアップロードはサーバーが断り（403）、はじめて送ったときに時刻を残す（`users.import_consent_at`）
- 送る前に次の4点を表示して、チェックしてから始める
  1. 読み取りは AI が行うので間違えることがある。保存前に必ず見直す
  2. 画像は読み取りのために外部サービス（Groq・Cloudflare）へ送られる。学習には使われず、送った先でも保存しない設定で使う。こちらの画像は読み取り後にすぐ消す（読めなかったときも3日で消す）
  3. 読み取りはふつう1分ほど。重なると順番待ちになる。終わったら時間割の画面（と、オンにしていれば通知）でお知らせする
  4. アプリ全体で1日の利用上限があり、混み合うと結果が届くまで時間がかかる
- 画像は四隅をドラッグして時間割の部分だけに切り抜ける。送る前にブラウザで長い辺1600px の JPEG にする。表の罫線やカードの隙間が見つかれば、授業の入っているマスだけを切り出して、曜日と時限を示す札を付けて縦に並べた画像にして送る（AI が列を数え違えて授業が別の曜日に入るのを防ぐため）。見つからないときは、切り抜いた画像をそのまま送る
- 待っている間は、いまの段階（画像を受け取った → 順番待ち／準備 → AI が表を書き写す → 見直して保存）と、送ってからの時間を出す。ほかに待っている人がいるときだけ「順番待ち中（前にあと○件・目安○分）」、無料枠を使い切った日は「今日／明日／○日後の朝（10時ごろ）にもう一度読み取ります」
- 読み取った授業名は `cleanTitle`（`src/lib/import.ts`）で整えてから使う。プロンプトを増やすと Llama が漢字を読み違えるので、AI の答えを直す形にしている。ⅡやⅣのようなローマ数字の記号は英字（II・IV）にする。学生ポータルが名前のあとに付ける印は取る：クラスや区分を示すかっこ（`(G1)`・`(G2-SA)`・`(SA-01)` のように、Gと数字、またはSAを含む英数字とハイフンのもの）と、読み取りに失敗しやすい `【ｾｯﾄ履修】`（かなが「ﾉ ﾉ」などに化けても、履の字を含む末尾のかっこは、閉じていなくても取る）。かっこが名前の一部のとき（`【前期】…`・`…【A】`・`(Gallery)`）は残す。同じ授業が別の読み方で並んでも1つにまとまる
- 読み取った結果は見直してから保存する
  - 授業ごとに、追加するか・授業名・曜日・時限・コマ数・教室・先生を直せる
  - 同じコマに「みんなの登録」の授業があれば「〇〇に合わせる」を選べる。名前が同じならはじめから選ぶ。合わせた授業は共有データの内容をそのまま使う（AI の読み違いで共有データを書き換えないため）
  - すでに時間割に同じ名前である授業は、はじめからチェックを外す。ほかの授業と重なるコマには注意を出す
  - 追加する学期を選ぶ（初期値は今の学期）。「みんなと同期する」は初期値オン
- 1人1日5回まで、読み取り中は2件まで
- 全員あわせて1日100件まで（無料枠の目安から。無料枠は日本時間9:00に戻る）。上限に達した日に送った画像は、断らずに受け付けて、翌朝10時ごろに読み取る（その朝の分も予約で埋まっていれば、その次の朝、と送る）。送る前の注意書きに「アプリ全体で1日の利用上限があり、混み合うと時間がかかる」と書き、上限に達しているときは、いつ読み取られるか（今日／明日／○日後の朝）も送る前に出す。後回しになった人には、読み取り中の画面にも出す
- 在籍確認済みの人（と運営）だけが使える。ほかの人には、画面の代わりに在籍確認のすすめを出す

## 友だち・グループ

- 友だちは申請して、相手が承認したら成立。承認されるまで時間割は見えない
- 申請のしかた：自分の友だちリンク（`/add/10文字のコード`）を送る、QR コードを読んでもらう、相手のコードかリンクを入れる。リンクはいつでも作り直せる（前のリンクは使えなくなる）
- 友だちリンクを開いた人がログインしていなくても、登録やはじめの設定のあとでそのページに戻る
- 相手から申請が来ているときに申請すると、そのまま友だちになる。返事待ちの申請は30件まで
- 届いた申請の数を下の「友だち」のタブに出す
- 表示名はニックネーム、アイコンは1〜2文字と色（9色、白い文字が読める濃さ）か写真。写真は端末で丸く切り抜いて256ピクセル四方の JPEG にしてから送り、承認した友だちと同じグループのメンバーにだけ `/icons/<id>` で返す（ほかの人には文字のアイコンが出る）
- 友だちの時間割では、授業と教室と今の授業が見える。メモ・資料・課題・休講は見えない。「友だちをやめる」「ブロックする」「通報する」
- ブロックすると友だちではなくなり、同じグループにいても時間割は見えない。ブロックした人は「友だち」の一番下から解除できる
- グループ（サークル・ゼミなど）は招待リンク（QR もある）で参加する。参加の画面で、そのグループに時間割を見せるかを本人が選ぶ。初期値は「見せる」
  - グループへの参加は本人が自分で押す操作なので、初期値は「見せる」にして手間を減らす
  - その代わり、参加の確認画面ではこの選択を必ず目に入る位置に出す。参加したあともグループの画面からいつでも変えられる
- グループを作った人は、名前の変更・招待リンクの作り直し・参加を承認制にするか・メンバーを退出させる・グループを消すができる。作った人が抜けると、いちばん前からいるメンバーに引き継ぐ（だれもいなければ消す）
- 「退出させる」と、その人は招待リンクを開いても参加できない（「このグループには参加できません」と出る）。リンクを作り直しても同じ。作った人がグループの画面の「退出させた人」から「参加できるようにする」を押すまで続く。自分から抜けた人は、リンクからまた参加できる
- 参加を承認制にすると、招待リンクの画面のボタンが「参加を申請する」になる。時間割を見せるかは申請のときに選び、承認されたらその選択で参加する。申請したあとは「申請を取り消す」で取り消せる
  - 作った人のグループの画面に「参加の申請（○）」が並び、「承認」か、×で断る。人数が100人に達していると承認できない
  - 「友だち」タブのグループの行に、作った人だけ「参加の申請 ○件」を出す
  - 申請が届いたとき（同じ人の2回目からは送らない）は作った人に、承認したときは申請した人に通知する。ほかのメンバーには、参加したときと同じ通知を送る。断ったときは通知しない
- グループのメンバーは100人まで

## ログイン

- メールでのログイン・登録は、リンクを送る。リンクは15分で切れ、1回だけ使える。開くと「（メールアドレス） でログインします。」と出て、「ログインする」を押すまで使い切らない（メールのスキャナーが開いても使い切らない）
- メールの数には決まりがある：
  - 同じアドレスには、60秒あけないと送れない。送ったあとの画面の「もう一度送る」は、60秒たつまで押せない（残りの秒数を出す）。「別のアドレスにする」で入力し直せる
  - 同じアドレスの使っていないリンクが3つあると、15分ほどたつまで送れない
  - ログインと在籍確認のメールは、アプリ全体で1時間に500通・1日に5,000通まで。超えたら、そのことを出し、パスキーがあればパスキーでログインできる、と添える。上限はレンタルサーバーが止まる線の3分の1（[architecture.md](architecture.md#回数制限)）
  - 同じ回線から短い間に何度も試すと、しばらく待つよう出る
- パスキーは、メール欄をタップしたときの候補にも出る。選ぶとそのままログインする。「パスキーでログイン」を取り消したときと、この端末にパスキーがないときは、メールでログインするよう案内する
- 退会と運営の画面は、開く前にもう一度ログインする（パスキー・Google・メールのどれでもよい）。「その他」の「退会する」と「運営」の行は、ログイン画面を通ってから開く。退会の画面は、ログインし直して10分以内。運営の画面は、10分使わないでいるとまたログインを求める
- ログイン画面と、メールのリンクを開いた画面（ログイン・在籍確認）は、ロゴと「コマあわせ」を上に固定し、下の内容（ボタンや案内）は下に固定する。下の内容の量が変わっても、ロゴは動かない。在籍確認の画面も「コマあわせ」で、その下に小さく「在籍確認」と出す。ロゴの重なりの色は、ダークのときもメイン画面と同じ
- メールを送るボタン（ログイン・在籍確認・お問い合わせ）は、送っているあいだ中でぐるぐる回り、送れたらチェックマークに変わる。そのあと「送信しました」の案内が下からすーっと上がってくる
- 「その他」の「ログイン中の端末」に、ログインしている端末を「iPhone・Safari」のように出し（最後に使った日つき）、この端末が先頭に来る。ほかの端末は、行の右のログアウトのマークのボタンで1つずつ、または「ほかの端末をすべてログアウト」でまとめて、ログアウトさせられる。この端末は「ログアウト」から。パスキーを消したあと、ほかにログイン中の端末があれば、ほかをすべてログアウトするか聞く
- ログアウトすると、その端末の通知も止まる。「ログイン中の端末」から外された端末も同じ

## 在籍確認

- 大学のメールアドレスに確認のリンクを送り、開くと「在籍確認済み」の印が付く
- 在籍確認していない人が使えないもの：みんなの授業データ（授業をさがす、その画面）、スクショから読み込む、共有データへの授業の書き込み（授業の追加は「自分だけで使う」になる）。時間割・友だち・コマを重ねる・すでに時間割に入っている授業は、そのまま使える
- ドメインを登録していない大学は確認できないので、上の機能は使えない（要望を送ってもらう）
- 印は友だちの一覧、友だちの時間割、グループのメンバー、友だちリンクの画面に出る
- アドレスはその大学のドメインか、`.` 区切りのサブドメインだけを通す（`fakedhw.ac.jp` は `dhw.ac.jp` として通さない）。ドメインを登録していない大学はまだ確認できない
- 1つのアドレスで確認できるのは1人。ほかのアカウントの確認に使われているアドレスでは確認できず、確認は別のアカウントに移らない（期限が切れたあとも、そのアカウントのものとして残る）。心当たりがないときは、お問い合わせへ案内する
- リンクは1日・1回だけ。申し込んだアカウントでログインして開く（ログインしていなければ、ログインしてから戻ってくる）。開いた画面に「（ニックネーム） さんのアカウントで、（大学名）の在籍確認をします」と確認するアドレスを出し、「確認する」を押すと済む。別のアカウントでログインしているときは使えず、ログアウトして入り直すよう案内する
- 確認のメールも、同じアドレスには60秒あけないと送れない。1人が使っていないリンクを持てるのは3つまで。「もう一度送る」「別のアドレスにする」は、ログインのメールと同じ
- 毎年5月1日に切れる。4月にもう一度確認してもらう（卒業後もメールが使える大学があるため）
- 確認をすすめる画面（`VerifyPrompt`。タブを開いて少したったときに出る）：
  - まだ一度も確認していない人には1回だけ（閉じたあとも繰り返さない）
  - 確認済みの人には、期限の30日前・14日前・7日前と、切れたあとに1回ずつ。確認し直すと、それ以降は出さない
  - どこまで出したかはアカウントに持つ（`users.verify_prompt_stage`）。通知をすすめる画面より先に出す
- 「その他」の在籍確認の行と在籍確認の画面には、期限まで31日以上あるうちは「確認済み」だけを出す。30日以内になったら「あと○日」を足して、色をつけて強調する（30日前の案内画面と同じ時期）

## その他の画面

| 区分 | 項目 |
|---|---|
| 時間割 | 時間割の管理（年度・大学・学期・時限と、その年度の全部の授業、単位数の合計）、過去の時間割、スクショから読み込む |
| 表示 | 表示する曜日、テーマ（端末に合わせる／ライト／ダーク）、時限と時刻、学期の区切り |
| アプリ | 通知、ホーム画面に追加、休講を同じ授業の人に知らせる（オン・オフ） |
| アカウント | アイコン、ニックネーム、大学、パスキー（名前の変更・削除・追加）、ログイン中の端末、在籍確認、データの書き出し |
| サポート | 不具合・要望を送る、お問い合わせ、開発を応援する（`SUPPORT_URL` があるとき）、利用規約、プライバシーポリシー、このアプリについて |

- 下にログアウトと退会。退会は、ログインし直してから開く
- 表示する曜日とテーマは、変えた時点で保存する
- 大学を変えるとき、ひな形のある大学なら学期と時限をその大学のものに入れ替えるかを選べる
- 学期の区切りを変えると、消えた学期の授業はその時期にあたる学期に移る（4学期制の Q1・Q2 → 2学期制の前期）。日付がなければ、1年の中の位置で移す
- 時限を減らしても、その時限の授業は消さない（時間割に出ないだけで、時限を戻すとまた出る）
- パスキーには、作ったときにパスワードマネージャー（iCloud キーチェーン・Google パスワードマネージャーなど）か端末の名前を付ける
- 不具合・要望と通報には、返信や確認のための連絡先として、登録しているメールアドレスも運営に届く。送る画面に先にそう書く。運営の一覧に、送った人のニックネームとメールアドレスを出す（退会すると消える）
- 不具合・要望はログインした人が送る。ログインしていなくても連絡したい人（退会した人など）は、お問い合わせから送る。「このアプリについて」にも入口がある
- 不具合・要望は、付ける端末の情報（アプリのバージョン・ブラウザ・画面の大きさ・開いていた画面・テーマ）を全部見せてから、付けるかを選んで送る。初期状態では付けない。1日10件まで
- 支援サイトへのリンクは「その他」と「このアプリについて」だけに置く
- 「データの書き出し」で、自分のデータ（アカウント、時間割と授業、メモ・課題・休講・資料の一覧、欠席、イベント、友だち、グループ）を1つの JSON ファイルで保存できる（`komaawase-日付.json`）。資料のファイルそのものは入らない

## 年度のまたぎ

4月になると、その年度の時間割を新しく作る。大学のひな形があればそれを、なければ前の年度の学期と時限を1年ずらして使う。古い時間割は「過去の時間割」として残り、学期を切り替えて見られる（今日の列は出さない）。

## 動き

- 画面の切り替えは View Transitions で動かす。下のタブどうしは、行き先の向きへ横にすべって切り替わり（右のタブへは右から入る。下のバーは動かない）、奥の画面は右から入って右へ戻り、授業はシートとして下から上がって下へ閉じる。ボタン・行・コマは押すと少し沈む
- シートと授業の画面は、上端までスクロールしていれば下に引いて閉じられる（引きが短ければ戻る）
- シート（下から出る画面）は、閉じるときも下へすべって消える（Escape・外側のタップ・閉じるボタンでも）。画面の下に出る通知も、消えるときはふわっと消える
- 友だち・グループのメンバー・パスキー・授業の課題や資料や休講やメモやイベントや欠席の一覧は、行が増えるときも減るときもすーっと開閉する。時間割は学期を切り替えると、選んだ学期のタブの印が次のタブへすべり、マスが左上から順に現れる（曜日・時限のない授業のカードはふわっと入れ替わる）。「みんな空いてるコマ」の札も出入りする
- 小さいボタンとチップも、押すと少し沈む
- 「動きを減らす」の設定の端末では動かさない

## オフライン

- ホーム画面に追加できる（Web アプリのマニフェストとアイコン）
- ホーム画面のアプリを1分以上裏に置いてから戻ると、最新の内容を読み込み直す。友だち申請が来ていれば、アプリのアイコンに件数を出す（対応している端末だけ）。追加のしかたは `/install`（iPhone・Android・パソコン。開いている端末のものを先に出し、Chrome・Edge ではボタンでインストールできる）
- 一度開いたページは端末に残し、電波がないときはそれを出す。時間割と今の授業はオフラインでも見られる。開いたことのないページは「インターネットにつながっていません」
- ログインやアップロード、変更の操作は残さない。ログイン画面が開くと（ログアウト・退会のあと）残したページを消す

### 電波がないとき・極端に悪いとき

- 画面の上に帯を出す。「オフライン」（黒）と「通信が不安定です」（オレンジ）の2つ。どちらにも「今日 12:40 の情報を表示しています」と、画面の情報をいつサーバーから取ったかを書く（日本時間。昨日以前は日付）
- 帯の右に更新ボタン（ぐるぐる）。押すと接続を確かめ、つながれば最新に更新する。まだなら「更新に失敗しました」と出す。帯が出ている間は自動でも確かめ続ける（5秒・10秒・20秒・30秒、以降は1分おき）
- 画面の下の通知は、つながっていないときに操作したり開けないページを開いたりしたときに出る。文は2つだけ：オフラインなら「オフラインのため、その操作はできません」、通信が不安定なら「通信が不安定のため、更新できません」（更新ボタンで失敗したときは、どちらも「更新に失敗しました」）
- 帯はすーっと出入りする（動きを減らす設定のときは、すぐ出入りする）。同期の進み具合の行も同じ
- つながったら、保存したコピーを最新にして画面を読み込み直す（画面はそのまま更新される）。緑の帯で「オンラインに復帰しました」を2〜3秒出す
- 保存したコピーは、アプリを開いて数秒後に、下の4つのタブ（時間割・重ねる・友だち・その他）を順に取り直して作る。新しいものは取り直さない：時間割は15分、ほかの3つは3時間以内に取れていれば省く（画面を開いて取れたものも数える）。ブラウザがデータ節約を求めているときは時間割だけ。更新ボタンは全部取り直す。授業などを変えたあとは、重ねる・その他のコピーは古い扱いにして、次の同期で取り直す。時間がかかるときは帯に「友だちを同期中 · 3/4」と進み具合を出す（速いときは出さない）。授業を変えたあとも、時間割のコピーだけ取り直す
- 電波が極端に悪くて返事が来ないときも、4秒で保存したコピーの時間割を出す（待ち続けない）。アプリを開いて0.7秒たっても返事がないときは、それまで画面を白いままにせず、中央にぐるぐるを出す（背景はテーマの色）。アプリの中でリンクからページを開くときは、0.4秒たってもまだなら、今の画面のまま中央にぐるぐるを重ねる（すぐ開くときは出さない）
- サーバーが要るものは使えない。押すと理由を出す：フォームの送信すべて、資料のアップロードなどの通信、授業の追加（コマ・授業をさがす・スクショ読み込み）と友だち・グループの追加。ボタンとリンクは薄くし、空きコマは枠だけにする
- 端末に保存していないページは開かず、その場に残って「オフラインのため、その操作はできません」と出す。保存しているかは、クエリも含めて見る：重ねる画面で、ほかの人を選ぶ（`?with=` が変わる）ときは、その人たちの時間割をサーバーから取るので、その組み合わせを前に開いていなければ同じ文を出し、選び方（チップの表示と、覚えておく Cookie）は変えない。別のページへ移るときは、そのページのコピーがあれば、クエリが違ってもそのコピーを出す（授業の画面から学期つきの時間割へ戻る、など）
- 全画面の「インターネットにつながっていません」には、「もう一度開く」と「時間割へ」のボタンがあり、そこで詰まらない

## 通知

- 「その他」→「通知」で、この端末で受け取るかを決める。テストの通知を送れる
- 友だち申請が届いた・承認された、スクショの読み取りが終わった、グループに人が参加した、作ったグループに参加の申請が届いた、グループへの参加が承認された、前の日の20時に明日の課題と予定を知らせる、をそれぞれオン・オフできる（すべての端末に効く）
- 前の日の20時の通知：明日締め切りでまだ済んでいない課題と、明日のイベント。1件なら「明日：○○（締め切り）」や「明日：○○」と時刻・場所、2件以上なら「明日は3件あります」と3件までの名前。押すと予定のタブが開く。送るのは20:00〜20:09に散らす（人ごとに毎日同じ分）
- ログアウトした端末には、通知は届かなくなる（[ログイン](#ログイン)）
- iPhone・iPad はホーム画面に追加したアプリで開いたときだけ受け取れる。そうでないときは追加のしかたへ案内する
- 通知を押すと、その画面（友だち、読み取った授業、グループ）が開く
- 運営には、お問い合わせが届いたときにも通知が行く（オン・オフの項目には入っていない）
- 授業の前の通知：授業が始まる時（開始時）と、5・10・15・30・45・60・90・120分前から、3つまで選べる（初期はオフ）。「3限 ○○ が10分後に始まります」の見出しと、「12:40開始 · E10」（教室があれば）の本文。すべての端末に届く。今年度の時間割で、その曜日・時限の授業のうち、学期の期間内で、隔週の授業はその週のものだけ。休講の日は送らない。2コマ続きは、2コマ目の前にも送る（「4限（2コマ目） ○○ が10分後に始まります」）。ただし1コマ目の授業中に当たる時刻は送らない
- 通知をすすめる画面：登録後の最初の起動（すでに使っている人は次の起動）で、時間割・予定・友だち・その他のどれかを開いて1.5秒後に下から出る。端末ごとに1回で、閉じたら出さない（ホーム画面のアプリは別の端末として数える）
  - まだオンにしていない端末：通知をオンにする。オンにすると10分前の通知もオンになる（すでに選んでいる人はそのまま）。ただし、アカウントで1台でも通知を受け取る端末があれば出さない（`/api/reminders` が端末の数も返す）
  - iPhone・iPad をホーム画面に追加する前：追加の手順（共有ボタン → ホーム画面に追加 → 追加したアイコンから開く）と、`/install` へのリンク
  - すでにオンにしている端末で、授業の前の通知をまだ選んでいない人：10分前でオンにする

## 運営

- 利用規約とプライバシーポリシーはアプリの中にある（ログインしなくても読める）。登録するときに同意したことになる、とログイン画面に書く
- 退会したら個人のデータは消す。ほかの人も使う共有授業データは消さず、変更履歴は匿名にする（[data-model.md](data-model.md#退会したとき)）
- 共有授業データには報告と、元に戻す仕組みがある
- 運営の画面のトップは `/admin` で、「対応が必要」（問い合わせ・通報・不具合・要望と、それぞれの未対応の件数）、「管理」（利用者・授業・利用者が作った大学）、「数字」（利用の状況）に分けてある。見られるのは `users.role` が `admin` の人だけ（D1 で手で設定する）。開くときにもう一度ログインを求め、10分使わないとまた求める
- 問い合わせ（`/admin/contact`）・通報（`/admin/reports`）・不具合と要望（`/admin/feedback`）は、それぞれの画面で見て対応済みにする。お問い合わせの行には送った人のメールアドレスがあり、押すと返信のメールが開く。休講の共有への通報には「その日の共有を消す」がある（押すと、その日への通報も対応済みになる）
- 利用者（`/admin/users`）：新しく登録した順に30人ずつ。ニックネームかメールアドレスでさがせる。1人の画面に、メールアドレス・大学・在籍確認・登録日・最後に使った日・受けた通報の数・状態を出す。時間割の中身は見えない
  - 警告を送る（500文字まで）。送る前に、相手にどう出るか下書きで見られる。警告は相手のすべての端末で画面いっぱいに出て、ほかの操作はできない。「理解しました」は10秒たつまで押せない。押した日は運営の画面に出る
  - 利用を止める：すべての端末からログアウトさせ、通知の宛先を消し、パスキー・Google・メールのどれでもログインできなくする（「このアカウントは、利用が制限されています。」）。止めている人は、友だち・グループのメンバー・みんなの休講の数に出ない。「利用を再開する」で戻せる
  - ニックネームを戻す（次に開いたときに決め直してもらう）、写真を消す、退会させる（元に戻せない）。どれも確認を出す
- 利用の状況（`/admin/stats`）：登録している人（この1週間の新しい人）、24時間・7日・30日に開いた人、在籍確認している人、利用停止の人、通知を受け取る人、授業の前の通知を使う人。直近30日の新しく登録した人と、24時間に開いた人のグラフ。時間割・授業・同期・共有授業・友だち・グループ・イベント・課題・休講・欠席の数。大学ごとの利用者（上位10）
  - 開いた人の数はあとから数え直せないので、毎日の Cron が1日1行 `daily_stats` に書く。グラフは書きはじめた日からになる
- `/admin/universities`（利用者が作った大学）に、利用者が入力した大学の名前と、それを選んでいる人の数を出す。3人以上になると、ほかの人の入力候補に出る
- 運営は `/admin` の「授業」（`/admin/courses`）で、大学と年度を選んで授業名・先生・授業コードでさがし、`/shared/[id]` の「運営が直す」で授業名・先生・教室を直せる（履歴に残り、元に戻せる）
- 一覧と授業の画面には「同期中 ○人・使用中 ○人」を出す（使用中は、同期を切って「自分だけで使う」にした人も含めて、その授業を時間割に入れている人）。「授業」の一覧は、学期（授業に付いている学期名）で絞れて、使用中が0人の授業は色付きの印で目立たせる（「使用中0人だけ」のチェックで、それだけを並べられる）。使用中が0人の授業だけ、授業の画面から削除できる（確認を出す。変更の履歴と、その授業への報告も消える。消す直前にもう一度確かめ、だれかが追加していたら止める）
- 同じ画面の「ほかの授業と同期させる」で、名前が少し違うだけで別の授業になっているものを、同じ大学・年度の授業にまとめられる。まとめる授業を使っていた人はまとめ先と同期し、内容もまとめ先のものになる。両方を1つの時間割に入れていた人は、まとめる授業が「自分だけで使う」になって今の内容のまま残る（すでに「自分だけで使う」にしていた人は、自分で書いた内容のまま）。まとめた授業は消え、履歴も消えるので元に戻せない。その授業への通報は対応済みになる（`mergeShared`）
