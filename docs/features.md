# 機能と画面の流れ

## 画面一覧

| 画面 | できること |
|---|---|
| ログイン | パスキーでログイン。はじめての人は Google かメールアドレスで登録 |
| はじめの設定 | 登録直後に、大学・学期の区切り・時限と時刻・表示する曜日・テーマを決める |
| 自分の時間割 | 学期（Q1〜Q4 など）の切り替え、今日と今の授業の表示、コマから詳細や追加へ |
| 授業をさがす | 空いたコマをタップすると開く。その曜日・時限の授業を共有データから選ぶ |
| 授業を追加・編集 | 授業名、先生（複数）、色（10色）、開講学期（複数）、曜日・時限と教室（複数）、同期するかどうか |
| 授業の詳細 | 授業が入ったコマをタップすると下から開く。メモ・資料・課題・休講の追加と一覧 |
| スクショから読み込む | ほかのアプリの時間割のスクショを AI で読み取る |
| コマを重ねる | 友だちやグループの時間割と重ねて、みんなの空きコマを探す |
| 画像で書き出す | 時間割を画像にして保存・共有する |
| その他 | 時間割の管理、表示、アカウント、サポート |

## 自分の時間割

- 学期はタブで切り替える。4学期制なら Q1〜Q4
- 時限の欄に開始と終了の時刻を出す
- 今日の曜日は丸で囲み、その列を少し濃くする
- 今受けている授業は、そのコマ自体を縦のプログレスバーにする（上から埋まっていく）。残り時間も出す
- 教室はコマの下に白い札で中央ぞろえ。休講は黒い札
- 授業名は単語の区切りで改行する。実装では BudouX を使う
- 2コマ続きの授業は1つのコマとしてつなげて表示する
- 曜日・時限のない授業（オンデマンド、集中講義）は、時間割の下に色付きのカードで並べる
- 土曜・日曜は設定で表示を切り替える

## 授業の追加

1. 空いたコマをタップする
2. 「授業をさがす」でその曜日・時限の授業が一覧で出る
   - 「シラバス」「みんなの登録（人数）」の札が付く
   - 同じ授業を取っている友だちのアイコンも出る
   - 授業名・先生・授業コードで検索できる
3. 選ぶと編集画面が開く。内容は共有データから入っている
4. 一番上で「みんなと同期する」か「自分だけで使う」を選ぶ
5. 見つからないときは「自分で入力する」か「スクショからまとめて読み込む」

週に何回かある授業は、1つの授業に曜日・時限を何個でも並べて一度に登録する。教室は曜日・時限ごとに入れる。

## 授業の詳細

- 曜日・時限と教室、開講学期、先生、同期しているかを表示
- 「追加する」の下に、メモ・資料・課題・休講の4つのボタン
- 課題はチェックボックスと締切までの日数
- メモ・資料・課題は授業ごとに持つので、どの曜日・時限から開いても同じものが見える
- 「編集」から授業の編集画面へ

## コマを重ねる

- 自分と、選んだ友だち・グループの時間割を1枚に重ねる
- 1人ずつ色の違う丸いアイコンで表す
- 同じ授業を取っている人は、授業名を1つにまとめてアイコンだけ並べる
- 空きコマは強調しすぎず、枠線だけの空っぽのマスにする
- 1マスに入りきらないときは、全部の時限の高さを揃えて伸ばす
- 下に「みんな空いてるコマ」の一覧
- 別の大学の友だちは時限の時刻が違うので、**時限番号ではなく時刻で比べる**

## 画像で書き出す

- 縦長（ストーリー用）と横長（LINE・X 用）
- 表示を切り替えられるもの：教室名、曜日、時限、時刻、アイコンとニックネーム
- すみに「コマあわせ で作成」の札を入れる。横長では上の行に置いてコマを大きくする
- 画像はブラウザ内で作る（SVG → PNG）

## スクショから読み込む

- 送る前に次の3点を表示して、チェックしてから始める
  1. 読み取りは AI が行うので間違えることがある。保存前に必ず見直す
  2. 画像は読み取りのために外部サービス（Groq・Cloudflare）へ送られる。学習には使われず、読み取り後に削除する
  3. 混んでいる日は順番待ちになる。終わったらお知らせする
- 送る前に時間割の部分だけに切り抜ける
- 読み取った結果は、ユーザーが確認・修正してから保存する

詳しくは [architecture.md](architecture.md#スクショ読み取り)。

## 友だち・グループ

- 友だちは申請して、相手が承認したら成立。承認されるまで時間割は見えない
- 表示名はニックネーム
- ブロックと通報ができる。ブロックはグループより優先する
- グループ（サークル・ゼミなど）に入るとき、そのグループに時間割を見せるかを本人が選ぶ。初期値は「見せる」

## その他の画面

| 区分 | 項目 |
|---|---|
| 時間割 | 時間割の管理、過去の時間割 |
| 表示 | 土曜日・日曜日の表示、テーマ（端末に合わせる／ライト／ダーク）、時限と時刻、学期の区切り |
| アカウント | アイコン、ニックネーム、大学、パスキー、在籍確認 |
| サポート | 不具合・要望を送る、開発を応援する（支援サイト）、利用規約、プライバシーポリシー |

- 不具合・要望はどの画面からでも送れる。アプリのバージョンやブラウザの情報は、送る前に中身を見せてから付ける
- 支援サイトへのリンクは「その他」と「このアプリについて」だけに置く

## 年度のまたぎ

新年度は新しい時間割を作り、古いものは「過去の時間割」として残す。

## 運営

- 利用規約とプライバシーポリシーは必須（スクショ読み取りがあるので特にプライバシーポリシー）
- 退会したらデータを完全に消す
- 共有授業データには報告と修正の仕組みを用意する
