# 見た目の方針

## 方針

- シンプルでわかりやすく、柔らかめ
- AI っぽい見た目は避ける：グラデーションの背景、光る演出、絵文字、Inter や Roboto などのありがちなフォントは使わない
- 紙の時間割表のような雰囲気にする。生成りの紙に墨の文字、差し色は朱と藍の2色だけ
- タップできる場所は 44px 以上

## ロゴ

朱と藍の角丸の四角（コマ）を2つ重ね、重なった部分が墨色になるマーク。「重ねる」をそのまま形にしている。

![ロゴマーク](assets/logo-mark.svg)

- 文字は Zen Maru Gothic の太字で「コマあわせ」
- キャッチコピー：友だちと、時間割を共有しよう。
- 書き出し画像のすみには「コマあわせ で作成」の札を入れる
- ダークモードでは、重なりを `multiply` から `screen` に変えて明るくする
- アプリのアイコン（`static/icons/`、`apple-touch-icon.png`、`favicon.ico`）は `scripts/make-icons.mjs` でこのマークから作る。生成りの地にのせ、maskable は切り抜かれても欠けないように中央の80%の中に収める

## 文字

| 用途 | フォント |
|---|---|
| 見出し・ロゴ | Zen Maru Gothic（500 / 700） |
| 本文 | Zen Kaku Gothic New（400 / 500 / 700） |

時間割のマスの中は、授業名 11px、教室 10px。スマホの幅で5文字入るように、マスの左右の余白は 3px にする。

### 授業中のコマ

コマ自体を上から埋まるプログレスバーにし、墨の2px の枠で囲む。塗りと「あと○分」の文字は、授業の色から OKLCH の relative color で作る（10色それぞれに色を決めなくて済むように）。ずらす量はモックの「きいろ」に合わせた。

| | ライト | ダーク |
|---|---|---|
| 塗り | 明るさ −0.07、鮮やかさ +0.045 | 明るさ +0.12、鮮やかさ +0.025 |
| 「あと○分」の文字 | 明るさ 0.4、鮮やかさ +0.03 | 明るさ 0.9、鮮やかさ +0.04 |

## 書き出す画像

いつもライトの配色で描く（共有した先で紙の時間割に見えるように）。曜日と時限の欄は文字の分の幅だけにして、コマを大きくする。

## Google のボタン

Google のブランドガイドラインに従う。色つきの G を、ライトでは白地に `#747775` の枠、ダークでは `#131314` に `#8E918F` の枠のボタンに置く。文言は「Googleで続ける」。単色の G は使えない。
